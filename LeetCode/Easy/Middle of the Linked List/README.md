# 876. Middle of the Linked List

- **Difficulty:** Easy
- **Link:** [middle-of-the-linked-list](https://leetcode.com/problems/middle-of-the-linked-list/)
- **Language(s):** java
- **Time complexity:** O(n)
- **Space complexity:** O(1)
- **Runtime:** 0 ms
- **Memory:** 43.1 MB

## Notes

Rule to remember:

Odd-length list: Returns the single middle node and everything after it.
Even-length list: Returns the second middle node and everything after it.
